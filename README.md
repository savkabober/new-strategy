# new-strategy

Планировщик траектории для точечного робота с ограничениями по ускорению и скорости.
Робот строит кусочно-постоянное bang-bang управление в виде пар `(угол ускорения, время)`,
минимизирует метрику по финальной позиции, финальной скорости, общему времени и времени
нахождения внутри круговых препятствий.

## Что умеет

- решает задачу для заданного сценария со стартом, целью и круглыми препятствиями;
- поддерживает два оптимизатора: `Newton` и `Nelder-Mead`;
- умеет автоматически наращивать число отрезков, если траектории не хватает гибкости;
- использует решатели уравнений 3-й и 4-й степени для оценки пересечений траектории с окружностями;
- генерирует случайные тестовые сценарии и измеряет время минимизации;
- умеет показывать процесс оптимизации в реальном времени через `SFML`, если библиотека установлена;
- сохраняет графический отчёт в `SVG` без внешних библиотек.

## Сборка

```bash
make
```

Для live-режима нужен `SFML`:

```bash
sudo apt install libsfml-dev
make clean && make
```

## Запуск

Запуск демонстрационного сценария:

```bash
./app
```

Запуск с выбором метода:

```bash
./app --optimizer newton
./app --optimizer nelder-mead
./app --optimizer both
./app --optimizer nelder-mead --segments 5 --max-segments 9
./app --input scenarios/demo.txt --optimizer nelder-mead --sfml-live --no-render
```

Пакетный прогон случайных тестов:

```bash
./app --tests 10 --optimizer both
```

Свой сценарий из файла:

```bash
./app --input scenarios/demo.txt
```

Без генерации графики:

```bash
./app --tests 20 --no-render
./app --tests 20 --segments 4 --max-segments 8
```

## Формат входного файла

```text
name demo
segment_count 4
max_segment_count 8
adaptive_segments 1
obstacle_radius 320
start -3400 -1200 250 80
goal 3350 1250 -180 0
obstacles 4
-1200 -350
-300 950
900 -850
1750 500
```

## Результат

- в консоль печатаются найденные пары `(угол, время)` и метрики качества;
- при включённой адаптации планировщик может сам увеличить число сегментов до `max_segment_count`;
- с флагом `--sfml-live` открывается окно, где текущая и лучшая траектория обновляются по ходу оптимизации;
- в папке `artifacts/` сохраняются `SVG`-файлы с препятствиями, стартом, целью, скоростями и траекторией.
